Funções do Sistema Allegronet
O AllegroNet possui algumas funções básicas que serão utilizadas em todo o sistema. Para facilitar o
aprendizado e a operação do sistema, a sua forma de operação (chamada de interface) seguirá sempre um
padrão.
Botões de Comando
Nas telas de operações são apresentados os botões de comando, que permitem realizar as operações de
cadastramento, alteração, exclusão e confirmação. Cada botão de comando geralmente tem uma tecla de
atalho associada; no caso de escritórios, onde é utilizado um monitor comum procure utilizar sempre as
teclas de atalho para ganhar velocidade na operação do sistema.
Quando um registro está sendo alterado ou incluído realiza a gravação dos dados digitados.
Descarta as alterações realizadas no registro de informações e volta à tela atual,
permitindo fazer uma nova alteração ou inclusão.
Apaga as informações digitadas na tela sem cancelar a ação.
Fecha a janela atual.
Localiza informações no sistema. Exemplo: serviços, cadastro de clientes e tickets.
Botões de Ação
Os botões de ação possuem a função do mouse e auxilia na movimentação dos dados no sistema, como
adicionar, diminuir ou ir para a próxima página.
Quando existem muitos registros na tela, permite avançar para a próxima página ou
voltar para a página anterior.
A partir do registro selecionado permite ir para o próximo registro ou para o anterior.
Adiciona ou subtrai os números ou valores do campo selecionado.
Abre a lista com os detalhes do registro selecionado.

Teclado Virtual [ALT+A]
O Teclado Virtual foi criado para digitação através do monitor touchscreen, dessa forma torna-se
desnecessário o uso do teclado. Para acionar o teclado virtual basta dar um toque sobre o botão [Alt+T]
Teclado.
O teclado virtual possui as mesmas funcionalidades de um teclado comum, as posições das teclas também
foram mantidas para melhor localização e adaptação. Para digitar toque as letras ou números desejados.
Para confirmar a digitação de um toque sobre o botão [F10] Confirmar.
Quando você acionar o teclado
virtual em um campo de data ou
hora, ele irá exibir um teclado
especifico para selecionar o dia,
mês, ano e hora.

Atendimento
No módulo Atendimento são registradas as vendas dos serviços, solicitação de coleta e entrega do delivery,
cadastro de novos clientes, entre outros. Para abrir dê duplo clique no atalho do módulo Atendimento.
As funções de atendimento estão concentradas na tela principal e também possuem acesso pelo teclado,
permitindo agilidade durante o uso.
São encontradas também as funções como: Movimentar Caixa, Leitura X, Redução Z, Pagamento dos
Faturados, Receber Retrabalho, Entregar por Ticket, Entregar por Peça, Disponibilizar, Entrega e inventário
Entregar por Cliente, Anular Ticket e Remitir Ticket, Grade de Entrega, Visualizar Ticket, Tabela de Preços,
Enviar Serviços para Terceiros, Finalizar Terceiros, Registro de Horário de Operadores, Relatórios
Operacionais, Liberação de Acesso e Fechar.

Recepção de Serviços [F5]
Para registrar a entrada de peças ou serviços dê um toque sobre o botão [F5] Receber ou pressione as teclas
[F5] do teclado.
No primeiro acesso do Atendimento o sistema irá abrir a tela de pesquisa de clientes. É nessa tela que você
irá identificar ou cadastrar o cliente. Para localizar digite o telefone ou nome ou código ou endereço ou CPF
do cliente através do teclado virtual e toque no botão [F3] Pesquisar. No campo Resultado serão listados
todos os nomes encontrados.
No botão [F11] Pagt. Pend. você pode imprimir a relação dos tickets que estão a pagar do cliente
relacionado.
Caso o cliente não esteja cadastrado, o sistema emitirá um alerta informando que o cadastro não existe e
abrirá a tela de cadastro do cliente. Você também pode acessar o cadastro e incluir um novo cliente através
do botão [F4] Incluir. Para alterar ou modificar o cadastro de um cliente pressione o botão [F2] Alterar.

Na tela de Cadastro de Clientes digite o Nome e Telefones, preencha as outras informações se necessário. É
importante preencher todos os dados dos clientes para efeito de ações de Marketing mais eficiente.

No campo Observação você pode cadastrar uma observação ou lembrete para ser exibido no Atendimento
durante a recepção de peças. Para confirmar o cadastro pressione o botão [F10] Confirmar.

Dica
Registre a maior quantidade possível de observações e detalhes, porque após a emissão se
faz importante para uma rápida localização na entrega da peça ou até mesmo para uma
possível indenização de defeitos posteriores que não foram registrados.
No botão Observ. você define os defeitos e sujidades da peça como por exemplo, basta dar um
toque sobre as observações desejadas.
Em Marca você informa a marca de fabricação da peça.
Para definir a estampa da peça, de um toque sobre o botão Estampa e selecione a opção
desejada.
No botão Serviço você define os serviços especiais a serem executados na peça.
O Sistema terá um serviço padrão, por exemplo, “Lavar” quando o segmento é Lavanderia.
O preço do serviço padrão será o valor principal da Tabela de Preços.
Além do serviço padrão (Lavar), o sistema permite que sejam selecionados outros serviços para a mesma
peça, por exemplo: impermeabilizante, ajuste de barra, barra original e entre outros.
A soma do valor dos serviços selecionados irá compor o preço final da peça.

Entregando os Serviços
Para finalizar o ticket quando o cliente vem retirar os serviços que já estão prontos é necessário fazer a baixa
dos mesmos. O sistema Allegro.Net permite fazer a entrega dos tickets de três formas:
 Entrega total por número de ticket [F6].
 Entrega por peças [CTRL+F6].
 Entrega de tickets por cliente [ALT+F6].
Entregar por Ticket [F6]
Para entregar as peças de um ticket apenas pelo número do mesmo clique no botão [F6] Entregar (Ticket).
O procedimento é bem simples, você pode localizar o ticket pelo número, OS ou número da Etiqueta. Digite o
número em seguida de um toque sobre o botão [F3] Pesquisar para listar as informações do ticket desejado.
Você pode baixar ao mesmo tempo quantos tickets forem necessários, basta repetir o procedimento.
Selecione a Forma de Pagamento dos tickets, o pagamento será padrão para todos os tickets listados na tela.
Caso tenha pesquisado um ticket errado, selecione o mesmo e de um toque sobre o botão Exclui.

OBS.: O campo Observação nas telas [F6] Entregar Cliente e [CTRL+F6] Entregar Peça tem a finalidade de

Entrega Parcial das Peças [CTRL+F6]
O sistema permite fazer apenas a entrega de algumas peças do ticket sem fazer a entrega total. Com isso é
possível confirmar o pagamento somente das peças a serem entregues, deixando o restante do pagamento
pendente para a próxima entrega. Pressionar o botão [CTRL+F6] Entregar (Peça).
Digite o número do ticket desejado e de um toque sobre o botão [F3] Pesquisar e marque as peças a serem
entregues através do botão Seleção.
Dica
O Entregar Peças é recomendado para entrega parcial das peças de um ticket, se deseja
entregar todas as peças utilize o botão [F6] Entregar (Ticket).
